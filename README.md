# Godot Endless Runner Game 3D

A simple 3-lane endless runner demo, which has been ported to XR using the
[Spatialize](https://github.com/GodotVR/spatialize) addon.

See [the full tutorial](TUTORIAL.md) describing how this was done.

## History

- [Godot-Runner-Game](https://github.com/hman278/Godot-Runner-Game) originally by hman278 for Godot 3
- [Ported to Godot 4](https://github.com/mujtaba-io/3d-endless-runner) mujtaba-io
- [Minor improvements](https://github.com/dsnopek/3d-endless-runner) by David Snopek
- Ported to XR (using the [Spatialize](https://github.com/GodotVR/spatialize) addon) by the Godot XR Team
